Artificial Intelligence (AI) is a technology that allows computers to perform tasks that normally require human intelligence, such as making decisions or understanding language. Machine Learning (ML) is a part of AI where computers learn patterns from data and improve their performance without being directly programmed for every task. For example, ML can be used for spam email detection and house price prediction. Deep Learning (DL) is a part of Machine Learning that uses neural networks with multiple layers to learn complex patterns from large amounts of data. For example, Deep Learning is used in face recognition and object detection. Deep Learning is very useful for Computer Vision because it can automatically learn important features from images, such as edges, shapes, and objects, which helps computers understand and classify images.
